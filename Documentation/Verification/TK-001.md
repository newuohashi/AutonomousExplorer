# TK-001 共通値型・失敗結果とテスト基盤

検証日: 2026-11-25 (JST)

## 実装

- CL-001 EntityRef: 種別付きの永続参照。Character GUIDをN形式へ正規化し、連番IDを不変カルチャの20桁で表現する。比較はKind、Ordinal IDの順。
- CL-002 WorldPosition: doubleのXZ位置・ベクトル、距離、線形補間、floorによるセル所属。UnityのTransformや物理状態を参照しない。
- CL-003 CellCoord: intのXZ座標、値の等価性・ハッシュ、X→Zの比較、上(+Z)・右(+X)・下(-Z)・左(-X)の近傍順。
- CL-004 OperationResult: 通常失敗コード、メッセージ、任意の関連EntityRef。状態変更・ログ出力の責務を持たない。defaultは未指定の失敗となる。
- Domain asmdefはnoEngineReferences=true。EditModeテストのみDomainを参照する。後続層のasmdefや未実装サービスは追加していない。

採用仕様: G3-003/015/020/021/027/061/085/086/093/097/129/134/135/141/142。
